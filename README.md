# Letter Lab

A letter-sound app for pre-readers, with a lesson guide for the grown-up.

- **Parent mode:** one letter at a time. A build, a story, a sound, and something to move, with a
  session log.
- **Kid mode:** a child who can't read yet plays alone. Everything is spoken, one glowing target at a
  time: hear the letter's sound, meet four words, find the one that starts with the sound, earn a
  star, then go play away from the screen.

It installs to a phone or tablet's Home Screen and works offline. There are no accounts, and
progress stays on the device. Names are typed in on the device and never stored anywhere else.

Built with plain HTML, CSS and JavaScript: no build step. See `CLAUDE.md` to work on it.

Fonts: Andika, Playfair Display, Cinzel and Inter, under the SIL Open Font License (`fonts/`).
